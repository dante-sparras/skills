### Map

**Too big for one session, and the route is unclear. A planner charts decisions with the user. Nothing is built.**

1. **Chart.** Start a planner that runs **wayfinder** with the user's idea. Done when it returns the map, with the tickets it could specify now on the tracker. If charting finds no fog, re-route to `feature` and have the same planner carry its interview on into **to-spec**.
2. **Hand over.** Each later session starts with `/auto-mode <map reference>` and works one decision.

**Reply:** the destination, the map link, the tickets on the frontier by name, and the command that continues the work.
